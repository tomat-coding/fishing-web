# Plan content

The goal isn't more pages; it's pages that a specific reader searches for, finds useful, and returns to, and that lead some of them to the TsureruKana app. Plans should be small, ranked and tied to evidence.

## 1. Know where things stand

- Read the SEO roadmap memory if present (it lists ideas already agreed and what's still open) and the current pages (`ls *.html`, the `index.html` cards).
- Ask for Search Console data if the user hasn't shared it: top queries and pages with impressions, clicks, CTR and position, ideally for the last 3 months. This is the best evidence you'll get. If they don't have it, proceed from research and say the plan is less certain.

## 2. Find opportunities

Look for these, in roughly this order of value:

1. **Queries the site already shows up for but doesn't answer well** (high impressions, low CTR, position 5–20). Often a title/description rewrite or a new section on an existing page wins more than a new page.
2. **Questions readers of existing pages will have next**: getting there from Tokyo/Osaka/Kyoto, renting gear, guided trips, fishing with kids, what to eat, winter vs. summer, what if it's closed. Each is either a section or, if it spans several lakes, a page.
3. **Seasonal content people return to**: a month-by-month calendar across the six lakes, season-opening notes (ice fishing, bass, shijimi), "this winter's ice status" style pages that get updated. These earn bookmarks and repeat visits, and match what the app does day to day.
4. **Gaps in what ranks today**: search the main queries (in English and Japanese) and note where the top results are outdated, Japanese-only, or missing practical detail. That's where an English, practical, up-to-date page can win.
5. **Supporting topics that link back to the lakes**: licenses, etiquette, tackle shops, species guides (wakasagi, smallmouth bass, shijimi), weather and moon phase. Keep the six-lake focus; a topic that doesn't connect back to them is a different site.

For each idea, sanity-check demand (do people search it? are there forum questions, Reddit threads, Q&A sites?) and whether the site can genuinely do better than what exists.

## 3. Recommend

Give the user a ranked plan of about 5–8 items, no more:

| Priority | Idea | New page or improve existing? | Reader & main query | Why now / evidence | Effort |
|---|---|---|---|---|---|

Then, for the top two, a short brief: working title, filename, the reader in one sentence, TOC outline, facts that need research, which pages should link to it, and how the app note fits.

Mention briefly any non-content levers you noticed (titles with low CTR, internal links missing, pages to refresh before their season), but keep the focus on content.

Ask which item to start with. A new page then goes through the write-article skill, an improvement through reader-review or refresh-page. Update the SEO roadmap memory with the agreed plan so the next session can pick it up.
